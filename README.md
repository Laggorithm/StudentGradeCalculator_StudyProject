# Student Grade Calculator

Учебный проект на C17. Все этапы реализации и локальной проверки завершены.
Логику добавляем постепенно, с отдельными коммитами для выполненных этапов.

## Работа в VS Code

Открыть именно папку `StudentGradeCalculator_Learning` через File → Open Folder.
Рекомендуемые расширения: C/C++ от Microsoft и CMake Tools.

- `Ctrl+Shift+B`: настроить и собрать проект через CMake.
- Terminal → Run Task → Run program: собрать и запустить в терминале.
- `F5`: собрать и запустить под отладчиком GDB (нужно расширение C/C++).

## Этап 1

`main.c` передаёт управление `app.c`, а `input.c` отвечает за ввод имени.
Имя может содержать пробелы; пробельные символы по краям удаляются.
Пустой ввод и строки длиннее 127 байт отклоняются с повторным запросом.
Ограничение задано в байтах: символы UTF-8 могут занимать несколько байт.
После успешного ввода программа печатает персональное приветствие.
При завершении потока ввода возвращает код ошибки без зацикливания.

## Этап 2

После имени программа спрашивает количество предметов: целое число от 1 до 1000.
Отклоняются пустые и слишком длинные строки, дроби, посторонний текст,
числа вне диапазона и переполнение. При ошибке ввод запрашивается повторно.

Модуль `student.c / student.h` хранит структуры `Student` и `Subject`.
Массив предметов выделяется через `calloc`; названия пока пустые, баллы и
оценки имеют маркер `GRADE_NOT_ENTERED`. После вывода имени и количества
предметов программа освобождает память и завершается.
## Этап 3

Для каждого предмета вводятся название (до 127 байт) и целые баллы от 0 до 100.
Названия могут содержать пробелы. Пустые и слишком длинные названия отклоняются.
Баллы проверяются существующей функцией ввода целых чисел.
После ввода выводится простой список названий и баллов.
Если ввод прерван, массив предметов освобождается перед завершением.

Временный тестер этапа 1 и его настройки удалены.

## Этап 4

Модуль `grading.c / grading.h` применяет шкалу:
90–100 → 5, 80–89 → 4, 70–79 → 3, 60–69 → 2, 50–59 → 1, ниже 50 → 0.

`Average Grade` — среднее арифметическое оценок отдельных предметов.
`Average Score` — средний процент баллов. Все предметы имеют одинаковый вес.
`Overall Grade` — оценка по шкале, применённой к среднему проценту без округления.
Это выбранное правило для общей оценки: способ её расчёта не уточнён в задании.
Баллы 85, 92 и 68 дают оценки 4, 5 и 2, среднюю оценку 3.67,
средний процент 81.67% и общую оценку 4.

## Этап 5

Модуль `report.c / report.h` выводит имя студента, количество предметов,
таблицу `Subject / Score / Grade` и итоговые значения с двумя десятичными знаками.
Ширина столбца названий автоматически подбирается по самому длинному названию;
баллы и оценки выравниваются по правому краю. Длинные названия не обрезаются.
Ширина рассчитывается в байтах и рассчитана на обычные английские названия.
Один и тот же формат вывода можно использовать для экрана и файла.
## Этап 6

После вывода на экран тот же отчёт сохраняется в `student_report.txt` в текущей
рабочей папке. При запуске через задачу VS Code это корневая папка проекта.
Предыдущий отчёт заменяется. В файл входят таблица и итоги, но не подсказки ввода.
Обрабатываются ошибки открытия, записи, сброса буфера и закрытия файла.
При ошибке сохранения программа сообщает об этом и завершается с ненулевым кодом.

## Этап 7: финальные проверки и материалы для сдачи

Проверки модулей (C17, без дополнительных библиотек):

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
ctest --test-dir build --output-on-failure
```

Интеграционные проверки требуют Python 3 и используют только стандартную библиотеку:

```powershell
python tests/verify_project.py build/StudentGradeCalculator.exe
```

Проверены 47 сценариев: пример задания, границы шкалы, неверный и слишком длинный
ввод, 127-байтовые имена, CRLF, завершение ввода, 1000 предметов, совпадение отчётов,
замена предыдущего файла и ошибка его открытия. Отдельные проверки модулей
проверяют инициализацию и освобождение памяти, неполные данные и ошибку записи.
Финальные проверки находятся в `tests`; временный тестер этапа 1 удалён.
Для сборки только программы можно добавить `-DBUILD_TESTING=OFF` при настройке CMake.

В папке `submission` находятся скриншоты и текстовые результаты проверок.
Скриншоты показывают реальные захваченные результаты тестов в браузере,
а не имитацию интерактивного терминала. Исходные журналы приложены рядом.
Архив для сдачи содержит исходники, CMake, инструкции, проверки и результаты;
сгенерированная сборка и каталог `.git` в архив не включаются.
Ссылку на GitHub нужно добавить при сдаче самостоятельно.

Из терминала:

```powershell
cmake --build build
.\build\StudentGradeCalculator.exe
```

GCC, GDB и CMake настроены для установленного здесь MSYS2: `C:/msys64/ucrt64/bin`.
На другом компьютере пути в `.vscode` нужно адаптировать.

## История работы

После завершения и проверки каждого этапа:

```powershell
git add src CMakeLists.txt README.md
git commit -m "Describe the completed step"
git log --oneline
```

Сообщение коммита должно описывать реальное изменение. Готовое решение из
другой папки в этот проект не переносится.

## Что потребуется для сдачи

- ZIP с исходниками и `CMakeLists.txt`.
- Ссылка на опубликованный Git-репозиторий. Сейчас репозиторий локальный;
  удалённый репозиторий подключим отдельно.
- Скриншоты результатов проверки готовой программы.

## План реализации

1. Приветствие и ввод имени студента.
2. Ввод количества предметов и проверка ввода.
3. Ввод названий предметов и баллов.
4. Преобразование баллов в оценки и расчёт среднего.
5. Отчёт на экране и запись того же отчёта в файл.
6. Проверки, скриншоты, публикация репозитория и архив для сдачи.
